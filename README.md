# didactic-octo-potato

This repository is managed and maintained with the assistance of **GitHub Copilot**, an AI-powered coding assistant developed by GitHub and OpenAI.

## 关于 / About

**你是什么模型？**

本仓库使用 **GitHub Copilot Coding Agent** 进行辅助开发。GitHub Copilot 是由 GitHub 与 OpenAI 合作开发的 AI 编程助手，基于大型语言模型（LLM）技术构建，能够理解代码上下文并提供智能代码补全、问题修复和代码生成等功能。

**What model are you?**

This repository uses the **GitHub Copilot Coding Agent** for assisted development. GitHub Copilot is an AI programming assistant developed through a collaboration between GitHub and OpenAI, built on large language model (LLM) technology. It understands code context and provides intelligent code completion, issue fixing, and code generation capabilities.
